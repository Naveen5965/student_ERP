# ERP-based Integrated Student Management System

A comprehensive ERP system for educational institutions that integrates student admissions, fee management, hostel allocation, and examination records into a single unified platform.

## Key Features

1. **Admission Forms**: Streamlined digital admission process using Microsoft Forms
2. **Fee Management**: Automated fee collection with UPI integration and digital receipt generation
3. **Hostel & Library Management**: Real-time tracking of hostel occupancy and library resources
4. **Admin Dashboard**: Centralized Power BI dashboard for institutional oversight
5. **Role-based Access Control**: Secure access management with Microsoft 365 integration
6. **Document Repository**: Secure cloud storage for academic documents
7. **Notification Service**: Automated alerts and notifications via Outlook API
8. **Chatbot Assistance**: MS Framebot integration for student and staff queries

## Technical Stack

- **Frontend**: Microsoft Forms, HTML/CSS/JavaScript
- **Database**: MS Excel Online, Cloud SQL, Supabase (Optional)
- **Automation Layer**: MS Power Automation, Node.js scripts
- **Payment Gateway**: UPI Integration (PhonePe), Automatic PDF Receipts (Node.js)
- **Reporting & Dashboard**: Power BI
- **Security & Access Control**: Microsoft 365 (role-based access), OAuth, Cloud Storage Backup
- **Chatbot**: MS Framebot
- **Notification Service**: Outlook API
- **Document Repository**: Cloud Storage for marksheets, ID cards, receipts
